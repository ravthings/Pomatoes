About

Pomatoes is a FIRST LEGO League team from Western Australia, competing in the Bioglow season. In FIRST LEGO League, a team builds and programs a robot to complete missions, researches a real problem and designs a solution for it, and shows its Core Values in everything it does.

These pages explain how we work, from the robot on the table to the code that drives it.

Pomatoes / Programming

Programming

Simple block code that everyone on the team can read.

Our approach

We program PMS Pomatoes in block code. We chose it because we want our programs to be easy to read, easy to understand and easy to view.

Easy to read
Blocks read like instructions, so the steps of a run are clear at a glance.
Easy to understand
Anyone on the team can follow what a program does and explain it to others.
Easy to view
A program fits on the screen, so we can check it, change it and show it quickly.

Pomatoes / Robot Game

Robot Game

How we approach the mission table.

The game

In the Robot Game, our robot runs timed matches on a themed mission table and earns points for the missions it completes. Every run has to be fast, but above all it has to work the same way each time.

Our strategy

We plan our runs around attachments. Each strategy has its own attachment, built for the missions that strategy covers.

Details to come. Our missions, our runs and how many points we aim for.

How we improve

We test every run again and again. When something fails, we find out why, change the robot or the program and test it again until it works.

Pomatoes / Innovation Project

Innovation Project

A real problem, and a solution we designed ourselves.

The project

Every FIRST LEGO League team chooses a real problem connected to the season theme, designs a solution and shares it with people who could use it. Our season is Bioglow.

Details to come. The problem we chose, our solution and who we have shared it with.

How we work

Identify
We research a problem and decide what we want to solve.
Design
We plan a solution and decide what it needs to do.
Create
We build a model or prototype of our idea.
Iterate
We test it, collect feedback and improve it.
Communicate
We share our solution with others and explain how it works.

Core Values

Six values that every FIRST LEGO League team shares.

Our values

Discovery
We explore new skills and ideas, and enjoy learning them.
Innovation
We use creativity and persistence to solve problems.
Impact
We use what we learn to make things better for other people.
